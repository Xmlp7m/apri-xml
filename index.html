Domande Frequenti sugli Allegati XML

Come posso aprire un file XML da iPhone o Android?

Ti basta premere sul box in alto, selezionare il file .xml salvato tra i tuoi documenti o scaricato da una mail PEC, e il nostro sistema lo trasformerà in una fattura chiara e leggibile in meno di un secondo.

I miei dati fiscali sono al sicuro?

Assolutamente sì. A differenza di altri siti, ApriXML elabora il file interamente all'interno della memoria del tuo smartphone o computer tramite codice JavaScript. Nessun file viene inviato o memorizzato su server esterni.

Come posso salvare la fattura in formato PDF?

Dopo aver caricato il file XML, premi sul pulsante "Stampa o Salva in PDF". Dal menu di stampa del tuo telefono potrai selezionare la voce "Salva come PDF" per conservare la fattura nel tuo dispositivo.
